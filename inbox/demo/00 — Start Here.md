# Start here — ZenNotes feature tour

This folder is a guided demo vault for ZenNotes as it exists today. It covers markdown rendering, keyboard-first workflows, search, views, settings, and the vault-level features that sit on top of plain files.

## How to use this tour

- Open notes in **Edit**, **Split**, and **Preview** to see where each feature is most useful.
- Use `Space p` or the outline panel on longer notes.
- Use `Space f` to search notes by title and path.
- Use `Space s t` to fuzzy-search text across the vault.
- Open **Help** from the footer or type `:help` from normal mode for the built-in manual.
- Try `⌘.` to toggle **Zen mode** while reading any note here.

## What this demo folder covers

ZenNotes is more than a markdown renderer. Across this folder you can try:

- plain file-based notes with no hidden database
- live preview plus dedicated preview and split modes
- heading folding and outline jumps
- wikilinks, tags, backlinks, and unresolved-link discovery
- quick capture via Quick Notes
- Inbox, Archive, and Trash as separate lifecycle stages
- vault-wide Tasks and Tags views
- note search and vault text search
- Mermaid, TikZ, JSXGraph, and function-plot diagram rendering
- optional external search backends like `fzf` and `ripgrep`
- slash commands and `@` date insertion
- Vim mode, leader hints, ex commands, and pane motion
- settings, keymap overrides, and appearance controls
- command palette, built-in Help, and seeded onboarding content
- reference-pane and floating-window workflows
- session restore for panes, tabs, built-in views, and window bounds

## The point

Every file here is ordinary markdown on disk. Open the folder in ZenNotes, `vim`, VS Code, or another markdown editor and the notes are still yours.
