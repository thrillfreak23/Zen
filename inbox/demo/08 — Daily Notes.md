## Quick capture and dates

Quick Notes are for fast capture. From there you can:

- keep the note in Quick Notes
- move it into Inbox
- archive it later
- trash it with confirmation if it is no longer useful

Date helpers are also built in:

- type `@` to insert **Today**, **Yesterday**, or **Tomorrow**
- the inserted value is an ISO date like `2026-04-16`
- ISO dates stay readable, sortable, and easy to search

Examples:

- Review due @today
- Follow up on search backend docs @tomorrow
- Closed the previous thread @yesterday
